Third-party listings sometimes show bands around ₹26 lakh–₹87 lakh depending on size and rate assumptions. Facing, pocket, and offers change the final number — ask sales after a site visit.

EOI / application fee vs booking

Some Atomoney application pages mention an EOI / application amount around ₹21,000 and clarify it is not allotment. That is different from a formal booking amount in an allotment letter. Always read the receipt terms before paying anything.
